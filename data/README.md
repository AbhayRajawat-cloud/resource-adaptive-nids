# Dataset Directory

## Raw Data (`data/raw/`)
Place the original, uncompressed dataset file here:
- `NF-UNSW-NB15-v2.csv`

> **Note:** The raw dataset should never be modified or overwritten. Raw data files are ignored by git (`.gitignore`).

## Processed Data (`data/processed/`)
Intermediate and processed artifacts generated by preprocessing, normalization, and windowing pipelines (e.g., Parquet / NPY files, partitioned client datasets) will be saved here.
